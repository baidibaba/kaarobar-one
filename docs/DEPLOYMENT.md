# Deployment Guide

## Vercel Deployment

### Prerequisites

- Vercel account
- GitHub repository connected to Vercel

### Environment Variables

Set these in Vercel dashboard (Settings → Environment Variables):

| Variable | Description | Required |
|----------|-------------|----------|
| `NEXT_PUBLIC_APP_NAME` | App name | Yes |
| `NEXT_PUBLIC_APP_VERSION` | App version | Yes |

### Deploy

1. Push to `main` branch
2. Vercel auto-deploys on push
3. Preview deployments for PRs

### Custom Domain

1. Go to Vercel Dashboard → Settings → Domains
2. Add your domain
3. Update DNS records as instructed

## PWA Deployment Notes

- Service worker is auto-generated by `next-pwa`
- Manifest is in `public/manifest.json`
- Icons are in `public/icons/`
- Test PWA features in production (not in dev mode)

## Build Optimization

- Images optimized by Next.js Image component
- Fonts loaded via `next/font`
- Code splitting automatic with App Router
