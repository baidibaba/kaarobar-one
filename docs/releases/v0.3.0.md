# Release Plan — v0.3.0

## Release Info

| Item | Value |
|------|-------|
| **Version** | 0.3.0 |
| **Type** | MINOR (new features, no breaking changes) |
| **Phase** | Phase 1 — MVP: User Selection & Home |
| **Branch** | `release/v0.3.0` |

---

## Features to Include

### 1. User Selection Screen
- Grid of user avatars
- Tap to select user
- Urdu + English names

### 2. PIN Input
- Numpad for PIN entry
- 4-digit PIN
- Error handling

### 3. Home Dashboard
- Welcome message with user name
- Today's summary
- Quick stats

### 4. User Management
- Add new user
- Edit existing user
- Delete user
- Role assignment (admin, worker, viewer)

### 5. Database Seed
- Default users for testing
- Auto-seed on first launch

### 6. Bilingual UI
- All text in English + Urdu
- Language selector (Both, English only, Urdu only)

### 7. Bottom Navigation
- 5 tabs: Home, Sale, Stock, People, Ledger
- Active state indicator

---

## Acceptance Criteria

- [ ] User sees language selection on first launch
- [ ] User sees grid of user avatars
- [ ] User can select user and enter PIN
- [ ] Dashboard shows welcome message
- [ ] Bottom navigation works
- [ ] User can add/edit/delete users
- [ ] All text in English and Urdu
- [ ] Language preference persists
- [ ] All data persists in IndexedDB
- [ ] App works offline

## Release Checklist

### Before Release
- [ ] All acceptance criteria met
- [ ] All tests pass
- [ ] `npm run build` succeeds
- [ ] No TypeScript errors
- [ ] No ESLint warnings
- [ ] CHANGELOG.md updated
- [ ] Documentation updated
- [ ] Manual testing done

### Release Process
1. Create `release/v0.3.0` branch
2. Update CHANGELOG.md
3. Build and test
4. Merge to `main`
5. Tag `v0.3.0`
6. Push with tags
7. Deploy to production
8. Delete release branch
